# Python Git VSCode Class Project

이 저장소는 파이썬 수업에서 진행한 실습 프로젝트들을 정리한 것입니다.  
VSCode와 Git을 활용하여 파이썬 코드를 작성하고 실행하는 연습을 했습니다.  

---

## 📂 프로젝트 구조
.
├── main_print_v1.py
├── main_print_v2.py
├── main_print_v1.ipynb
├── requirements.txt
└── .vscode/
    └── settings.json

---

## 📌 파일 소개
- main_print_v1.py  
  파이썬 기본 출력 및 딕셔너리 출력 연습 코드  

- main_print_v2.py  
  main_print_v1.py를 확장하여 조금 더 구조화된 출력 테스트  

- main_print_v1.ipynb  
  주피터 노트북 버전, 코드 실행 및 시각적인 결과 확인 가능  

- requirements.txt  
  프로젝트 실행에 필요한 파이썬 라이브러리 목록 (pip freeze로 생성)  

- .vscode/settings.json  
  VSCode 환경 설정 파일  

---

## ⚙️ 실행 방법
1. 가상환경 생성 및 실행  
   python -m venv .venv  
   .venv\Scripts\activate   # (Windows)  
   source .venv/bin/activate  # (Mac/Linux)  

2. 라이브러리 설치  
   pip install -r requirements.txt  

3. 코드 실행  
   python main_print_v1.py  
   python main_print_v2.py
